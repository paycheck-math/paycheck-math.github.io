Privacy Policy

Last updated: October 18, 2026

Paycheck Math Uploader ("the app") is a private tool used only by the owner of the Paycheck Math YouTube channel to upload that channel's own videos through the YouTube Data API.

What data the app uses

The app accesses only the channel owner's own YouTube account, with the owner's permission, to upload videos, set titles, descriptions and thumbnails, and schedule publishing. It does not access, collect or store data about any other person.

How data is stored

The access credentials are stored as encrypted secrets in the owner's private GitHub repository. No data is sold or shared with third parties.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
